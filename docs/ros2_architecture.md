# Vayuputra ROS 2 Architecture

## Package Structure

| Package | Responsibility |
|---|---|
| `vayuputra_bringup` | Bringup, configuration and launch orchestration |
| `vayuputra_detection` | Survivor detection ROS 2 integration |
| `vayuputra_exploration` | Autonomous exploration ROS 2 integration |
| `vayuputra_interfaces` | Shared ROS 2 message definitions |
| `vayuputra_mavlink` | ROS 2 ↔ MAVROS/MAVLink ↔ PX4 integration |
| `vayuputra_mission` | Mission-level coordination and integration |
| `vayuputra_navigation` | Nav2-based navigation integration |
| `vayuputra_sensors` | Sensor ROS 2 integration |
| `vayuputra_slam` | RTAB-Map SLAM / localization integration |
